# Living Nexus — Adaptive Experience Architecture v0.1

Status: DESIGN / IMPLEMENTATION ROADMAP, NOT DEPLOYED. Supplements the canonical continuation contract and design constitution. No public launch permission.

## Prime directive
The world is a single, coherent, organic auric environment, never a dashboard or collection of widgets. Intelligence is expressed through subtle field behavior and purposeful assistance, not visual noise.

## Progressive experience tiers
- Tier 0 (no JavaScript / low power): readable semantic navigation, accessible links to all pocket dimensions, functional core content.
- Tier 1 (standard): SVG/CSS auric membranes, slow energy flow, pointer/keyboard-responsive resonance, Living Thread with browser-local storage and explicit Dissolve.
- Tier 2 (capable hardware, opt-in): richer shader-driven spatial atmosphere, context-responsive field currents, low-overhead depth and motion; monitor frame times and automatically degrade gracefully.
- Tier 3 (explicitly connected): Cloudflare Worker gateway for consented AI assistance, optional retrieval from public project corpus, rate limits and cost ceilings. Never expose provider keys or Silver data to client bundles.

## Experience intelligence
- Guide Me uses explicit visitor choices only; do not infer medical or psychological traits.
- Constellation relationships can suggest adjacent worlds with explainable links.
- Memory is inspectable, exportable, and clearable; default session-only for visitors.
- Any learning/adaptation must be consented, reversible and scoped to the current user. No covert profiling.
- Live prompts/audio require prominent consent, clear listening state, immediate stop and no automatic raw audio retention.
- Support screen readers, keyboard access, reduced motion and low-bandwidth modes.

## Architecture boundaries
- Frontend: visual engine + deterministic navigation and accessibility layer.
- Backend (future): narrowly scoped Cloudflare Workers API with server-side auth, input validation, request budgets, telemetry stripped of sensitive content, per-user rate limiting and feature flags.
- Storage (future): D1 for explicit persistent structured records; R2 for approved public assets; Durable Objects only if strong consistency or real-time collaboration proves necessary.
- Separate deployments, secrets, identity and retention for Silver versus public Archon Soulings. No shared public/private memory.
- No automatic paid AI calls or background compute by default.

## Quality and sustainability gates
- Target responsive evidence at 390, 820 and 1280 widths, plus actual iPad Safari.
- No JavaScript syntax/runtime errors; preserve complete pocket routes and return focus.
- No unintended horizontal overflow; minimum 44px practical touch targets.
- Establish performance budgets from real devices: first meaningful navigation, frame pacing, memory and network payload. Tune after measurement, not by arbitrary visual simplification.
- CI: static privacy scan, syntax check, browser smoke, screenshot evidence, owner visual approval. Add stable visual-diff fixtures only after reference binaries are versioned.
- Operations: pinned deployment SHA, rollback artifact, health checks, monthly cost ceilings and clear incident owner.
- Cloudflare account access is confirmed, but no Worker has been deployed or budget approved by this document.

## Feature delivery order
1. Fix JavaScript runtime failures and undersized targets; get CI green.
2. Validate screenshots against owner references; reject visual drift.
3. Install full build on isolated Wix preview; real iPad Safari acceptance.
4. Implement optional responsive field engine with automatic quality adaptation and Stillness.
5. Add secure public AI gateway behind a feature flag, explicit user consent and measured cost budget.
6. Expand optional memory and collaboration only after privacy/security reviews.

## Explicit prohibitions
No unapproved homepage replacement, public Silver references, fabricated Aureglossa glyphs, compulsory audio, invisible AI monitoring, always-on inference, or deployment claims based on generated concept images.
