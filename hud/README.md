# Aureglossa Neural HUD — Public Graph Contract

The Neural HUD is a public derived visualization of Estate #000001.

## Boundary
The HUD MUST consume only a public export. It MUST NOT query private steward-review storage, contributor contact data, unpublished Stones, donor information, credentials, or wallet secrets.

## Public graph
Schema: `gestalt-public-estate-graph/0.2`

A public node should include an ID, label, kind, state, canon classification, description, source IDs and visualization coordinates. Relationships become synaptic edges.

## Sustainability invariant
**Revenue ≠ donation ≠ investment ≠ NFT sale ≠ grant.**

The HUD may visualize these as separate paths but must not represent a channel as active without evidence.
