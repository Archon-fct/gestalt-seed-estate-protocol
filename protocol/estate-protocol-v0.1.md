# Estate Protocol v0.1 — PROVISIONAL

Estate Protocol is a proposed infrastructure layer for mixed human/AI creative estates.

It does not replace Gestalt Seed Protocol v1.0 governance.

## Objects

### ESTATE
A stewarded collection and authority boundary.

### ASSET
A creative, technical, cultural, contractual, digital, or physical object recorded by an Estate.

### IDENTITY
A human, organization, collective, AI system, or agent associated with contributions or transactions.

### LICENSE
Machine- and human-readable permission terms for use of an Asset.

### TRANSACTION
A sale, license, contribution, royalty, transfer, claim, commission, or other economic/provenance event.

### PROVENANCE
Evidence describing origin, contributors, versions, permissions, relationships, hashes, and relevant external records.

## Design invariant

**Work ≠ File ≠ Edition ≠ NFT ≠ Copyright.**

These may be related but must not be collapsed into one record.

## Reference loop

Register → Prove → License → Quote → Approve → Pay → Split → Receipt → Provenance update.

## Estate #000001
Gestalt Seed is the reference implementation.

## Status
This specification is PROVISIONAL. Technical implementation does not silently change Gestalt Seed canon or human stewardship.
