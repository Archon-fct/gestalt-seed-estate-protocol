# Darchon.nft

**Role:** Web3 identity / provenance root for Estate #000001.

Current ownership/control is steward-reported unless independently verified onchain.

Intended uses:
- public Web3 identity
- provenance reference
- decentralized publication pointer
- optional public receiving-address resolution
- NFT/digital-edition namespace

Darchon.nft does **not** automatically own every Gestalt Seed work and does not itself authorize signing, transfers, minting, contract deployment, or rights grants.

Private keys and recovery phrases must never be stored in Estate metadata.
